Chaotic Bounce & The Struggle

The Process

The assignment was challenging in a fun way. Working with AI helped lead me to a solution.

The first version of the code gave me randomness, but no sound. While adding sound, I realized there were multiple steps needed to make it work.

1. Add sound variables near the first let line

let shapeSound, bounceSound;
let soundEnabled = false;

2. Add this at the end of setup()

// Create two sound effects, initially silent.
shapeSound = new p5.Oscillator("sine");
shapeSound.amp(0);

bounceSound = new p5.Oscillator("triangle");
bounceSound.amp(0);

3. Replace the random-change section

// Each frame has a 2% chance of changing direction and shape.
if (random(1) < 0.02) {
  VelX = random(-5, 5);
  VelY = random(-5, 5);

  let previousShape = shapeType;
  shapeType = floor(random(3));

  // Beep only if the shape actually changes.
  if (shapeType !== previousShape && soundEnabled) {
    shapeSound.freq(440 + shapeType * 220);
    shapeSound.amp(0.15, 0.01);
    shapeSound.amp(0, 0.15, 0.02);
  }
}

4. Add the bounce sound

Add playBounce() after reversing the velocity inside each edge check. 

// Inside the left and right edge check:
VelX *= -1;
playBounce();

// Inside the top and bottom edge check:
VelY *= -1;
playBounce();

5. Add these functions at the bottom of the code

// Click once to enable sound.
async function mousePressed() {
  await userStartAudio();

  if (!soundEnabled) {
    shapeSound.start();
    bounceSound.start();
    soundEnabled = true;
  }
}

// A low, short tone when the shape touches an edge.
function playBounce() {
  if (soundEnabled) {
    bounceSound.freq(180);
    bounceSound.amp(0.2, 0.01);
    bounceSound.amp(0, 0.1, 0.02);
  }
}

Adding an element that ties into multiple actions requires way more input than I thought it would.
